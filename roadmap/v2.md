# Roadmap v2

Printsip: har bosqich **ishga tushirsa bo'ladigan holatda** tugaydi. Bosqich ichidagi tartib
majburiy; bosqichlar orasida faqat ko'rsatilgan bog'liqlik.

## B0 — Poydevor (hozir)

- docs: vizyon, biznes qoidalari, domen modeli, arxitektura, ADR-001 ✅ (shu commit)
- backend: Maven skeleti, Spring Boot, PostgreSQL/Flyway, Testcontainers, Modulith, CI —
  `mvn clean verify` yashil
- android: Gradle skeleti, Compose app moduli, CI yashil

**Gate:** uchala repo CI yashil.

## B1 — Kompaniya va kirish

- backend: `Company`, `CompanyMember` + rollar, tenant context, repository scoping, haydovchi
  autentifikatsiyasi (telefon + aktivatsiya kodi + sessiya), audit
- android: aktivatsiya oqimi, PIN/biometrik ochish, kompaniya konteksti
- docs: ADR-002 autentifikatsiya modeli (avvalgi ADR-019 tahlilini meros qilib)

**Gate:** boshqa kompaniya ma'lumotiga kirish testlari qizil; haydovchi telefonda kiradi.

## B2 — Flot va reys

- backend: `Driver`, `Vehicle`, `Assignment`, `Customer`, `Trip` (PLANNED→ACTIVE→COMPLETED/CANCELLED)
- android: haydovchiga o'z reysini ko'rsatish
- docs: reys lifecycle qoidalari aniqlashtiriladi

**Gate:** operator API orqali reys ochadi, haydovchi ilovada ko'radi.

## B3 — Pul

- backend: `Money`/`FxSnapshot`, `Expense` (DRAFT→SUBMITTED→APPROVED/REJECTED), `Advance`,
  append-only `LedgerEntry`, idempotency komponenti
- android: offline xarajat kiritish, sync navbati, holatlar (qabul qilindi / kutilmoqda / rad)
- docs: ADR-003 offline sync va terminal-xato siyosati (avvalgi OPEN-002 merosini yopadi)

**Gate:** samolyot rejimida kiritilgan xarajat tarmoq qaytgach serverga yetadi, ikki marta
yozilmaydi, tasdiqlangach ledger'da ko'rinadi.

## B4 — Hisob-kitob va operator konsoli

- backend: `Settlement`, haydovchi balansi, operator tasdiqlash API'lari
- web: repo ochiladi — shell, xarajat tasdiqlash navbati, haydovchi balansi
- docs: ADR-004 web klient arxitekturasi

**Gate:** to'liq halqa — haydovchi kiritdi → operator tasdiqladi → ledger → hisob-kitob yopildi.

## B5 — Pilot

- performance baseline, security tekshiruvi, backup/restore mashqi, operator protsedurasi
- bitta haqiqiy kompaniya bilan pilot

## Keyin (B6+)

Yoqilg'i nazorati, ta'mirlash/kafolat, muvofiqlik (TIR/DAZVOL), alertlar, analitika va Owner
Cockpit — pilot tajribasiga qarab tartiblanadi.
